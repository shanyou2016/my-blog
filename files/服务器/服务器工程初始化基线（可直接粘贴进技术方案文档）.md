# 服务器工程初始化基线（可直接粘贴进技术方案文档）

> 说明：对标 Android Studio 工程初始化三条规范，**后端不依赖本机 IDE 配置来保证一致性，约束全部固化到项目代码、构建脚本、CI 环境，保证不同开发机器、CI 流水线、容器环境编译运行结果完全一致**。
> 
> 

## 1\. 环境一致性（对标：AS 关闭自动更新）

> 后端不采用「关闭 IDE 自动更新」这种本机操作，IDE 可正常升级；靠项目脚本锁定编译运行环境。
> 
> 

1. 项目明确锁定 JDK 版本，pom/gradle 中指定`source`/`target`字节码版本，不依赖本机 IDE 的 JDK。

2. 使用 `mvnw` / `gradlew` 包装脚本提交至 Git，统一构建工具版本，避免本机 Maven/Gradle 版本差异。

3. 所有 Maven/Gradle 依赖**全部使用固定精确版本号**；禁止使用 `+`、`latest.release` 动态版本；开启依赖锁文件 \(`*.lockfile`\) 并提交 Git。

4. Docker 镜像、CI 基础镜像禁止使用`latest`标签，使用固定版本 tag。

## 2\. 全链路 UTF‑8 编码（对标：Android 全局 UTF‑8，必须落实）

> 不能只设置 IDE 编码；编译、JVM 运行、日志、数据库、中间件全链路统一 UTF‑8，解决设备告警中文、平板上报中文日志、接口中文乱码。
> 
> 

1. IDE 工程文件编码设置为 UTF‑8（开发环境基础）。

2. Maven 编译插件强制指定`encoding=UTF‑8`。

3. SpringBoot 开启 Servlet 强制 UTF‑8 编码。

4. **JVM 启动脚本、Docker 启动参数必须追加 ****`-Dfile.encoding=UTF‑8`**。

5. 日志框架 \(logback/log4j2\) 输出编码设置 UTF‑8。

6. 数据库库、表字符集使用`utf8mb4`，连接串指定编码。

## 3\. 清理脚手架冗余代码（对标：删除 HelloWorld、默认 Demo 代码，强烈建议）

> 目标：工程包结构严格遵循既定五层架构，避免新人误拷贝示例代码，减少无关依赖与配置干扰；**保留必要业务骨架，不追求绝对空白工程**。
> 
> 

1. 删除 Spring 脚手架自动生成的示例 Controller、示例单元测试、页面模板代码。

2. 移除未使用的 starter 依赖（如 thymeleaf 等不需要的组件），减小包体积与攻击面。

3. 删除配置文件中大段注释示例片段，只保留业务实际生效配置项。

4. 禁止保留`demo`/`sample`/`example`包；包结构：`infrastructure、gateway、codec、state、business`。

5. 提交代码前清理未使用 import、无效空方法。

6. 保留骨架组件：全局异常处理器、日志配置、线程池配置，不属于冗余，不可删除。

## 4\. 后端特有基线（Android 无，项目新建即就位）

1. 完善`.gitignore`：忽略编译产物、IDE 本地配置、日志、临时文件。**数据库密码、MQTT 密钥、token 禁止硬编码提交 Git，使用环境变量注入**。

2. 线程池大小、超时、重试、限流等业务参数全部写入配置文件，禁止代码中大量硬编码。

3. 日志统一格式，关键链路埋点；敏感信息（密钥、完整 token）禁止完整打印日志。

4. 模块全部继承`AbstractManager`，严格遵守幂等 start/stop 生命周期。

> 核心原则：**所有约束尽量写在项目里，不靠开发人员本机 IDE 的手工设置来保证工程正确性**。
